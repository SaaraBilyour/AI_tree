Tree Visualization and Traversal

This project visualizes and traverses a binary tree using Graphviz and Python.

Features

Graphical Representation: Uses Graphviz to generate a PDF visualization of the tree.
Tree Traversal:
Inorder Traversal (Left → Root → Right)
Preorder Traversal (Root → Left → Right)
Postorder Traversal (Left → Right → Root)

Tree Representation in Memory: Nodes are also stored as Python objects.

Installation

Install dependencies:
pip install graphviz


Ensure Graphviz is installed and available in your system path.

Usage
Run the script:
python arbres.py

This will:

Generate and display a PDF visualization of the tree.
Print Inorder, Preorder, and Postorder traversals.
